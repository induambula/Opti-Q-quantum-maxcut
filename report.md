## 2. Abstract

This project investigates the Weighted Max-Cut problem
using classical optimization and the Quantum Approximate
Optimization Algorithm (QAOA).

A weighted graph is used to identify a partition that
maximizes the total weight of edges connecting two groups.

The classical optimum is compared with QAOA simulation
results. Circuit transpilation is also used to investigate
how processor connectivity influences circuit depth and
routing overhead.

## 3. Problem Statement

PS-O1: Max-Cut on Weighted Graphs

Given a weighted graph, divide its vertices into two
groups to maximize the total weight of edges connecting
vertices belonging to different groups.

## 4. Methodology

### 4.1 Graph Construction

A six-vertex weighted graph is loaded from a JSON file.

### 4.2 Classical Optimization

All possible vertex partitions are evaluated to determine
the maximum weighted cut.

### 4.3 QAOA Implementation

A QAOA circuit with p = 1 is implemented using Qiskit.

The circuit uses Hadamard gates to initialize a
superposition, RZZ gates for the problem interactions,
and RX gates for the mixing operation.

### 4.4 Parameter Optimization

The gamma and beta parameters are optimized using
a classical optimization routine.

### 4.5 Processor Benchmarking

The circuit is transpiled against two illustrative
coupling topologies to investigate circuit depth and
routing overhead.

## 5. Classical Results

The classical optimization produced the following results:

- Number of vertices: 6
- Number of edges: 9
- Classical optimum cut value: 16

The optimal partition obtained in the current run is:

- Group 0: Vertices 0, 1, 3
- Group 1: Vertices 2, 4, 5

## 6. QAOA Results

The QAOA circuit is evaluated using local quantum
simulation with Qiskit Aer.

The following metrics are generated by the program:

- Optimized gamma parameter
- Optimized beta parameter
- Expected cut value
- Best observed cut value
- Approximation ratio
- Execution time

The approximation ratio is calculated as:

Approximation Ratio = Expected Cut Value / Classical Optimum

The exact values should be taken from the generated
results for the corresponding execution.

## 7. Processor Benchmarking

Processor A and Processor B are represented using
illustrative coupling topologies.

The circuit is transpiled to examine:

- Circuit depth
- Two-qubit gate count
- Routing overhead

The comparison helps investigate how connectivity
constraints can affect the transpiled circuit.

## 9. Limitations

The processor coupling topologies used in the current
implementation are illustrative and have not been
verified as official processor configurations.

The results represent local simulation and circuit
transpilation, not physical quantum hardware execution.

QAOA outcomes can vary with optimizer behavior,
parameters, and measurement sampling.
